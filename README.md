### `02` — featured projects

#### 01 / Financial Document Intelligence
**Hybrid RAG · Knowledge Graphs · LLM Evaluation**

A financial question-answering system designed for

- Hybrid retrieval combining BM25 and dense embeddings
- Cohere reranking to improve document relevance
- Neo4j knowledge graph for entity relationships

- FastAPI and Streamlit-based application pipeline

#### 02 / Memory-Augmented GPT-2
**LLM Research · External Memory · Retrieval**

Exploring whether a bounded external memory can improve
language modelling without scaling the backbone.

- Implemented scalar and vector memory-write gating
- Designed top-k memory routing and GRU-based updates
- Investigated memory-slot collapse and retrieval failures
- Explored E5-based addressing and occupancy-aware routing
- Reduced validation perplexity from **33.15 to 29.60**
  in initial experiments

`PyTorch` `Transformers` `GPT-2` `E5`

---

#### 03 / Cross-Dataset Intrusion Detection
**Distributed ML · Mixture of Experts · Research**

A distributed intrusion-detection framework designed
to evaluate generalization across heterogeneous datasets.

- Unified network-flow feature representation
- Random Forest and Logistic Regression experts
- Stacked meta-learning for expert aggregation
- Apache Spark and Hadoop-based processing
- Leave-one-dataset-out evaluation across
  NSL-KDD, CICIDS2017, and Bot-IoT

**Published at ICCUBEA 2026**

`Python` `Apache Spark` `Hadoop` `Scikit-learn`
